<h3 align="center">One payment. Any interface. Final by design.</h3>

Payrail is payment infrastructure for wallets, merchant checkout, POS, SMS and future applications. Every channel resolves to the same signed operation, deterministic ledger state and independently verifiable final receipt.

### Platform

- **Network** — the Payrail ledger, signed operations and durable devnet runtime.
- **Wallet** — self-custody browser wallet with encrypted local keys and hosted checkout.
- **Explorer** — independent transaction, block and finality inspection.
- **Merchant Portal** — omnichannel payment requests for web, QR and SMS.
- **SDK** — typed clients, canonical monetary values and signing primitives.
- **UI Kit** — the shared Payrail brand, tokens and product components.
